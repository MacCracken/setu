# cyrius 6.6.17 — `cyrius coverage` can count the RUN programs (information)

**Filed:** 2026-10-05 by the cyrius 6.6.17 release docs · **Status:** information — nothing to do until
cyrius 6.6.17 is tagged and out; this repo's to adopt when it pins ≥ 6.6.17. Nothing here gates a cyrius
release.

`cyrius coverage`'s corpus was `tests/**/*.tcyr` only, so a repo that tests through RUN programs read ~0 %
(rekha filed it as cyrius P5; setu was one of the repos measured the same). From cyrius 6.6.17 (its m7,
P5-A):

- `[coverage] programs = ["programs/*_test.cyr"]` in cyrius.cyml (or `cyrius coverage --programs <glob>`,
  repeatable; the flag replaces the manifest list) adds each matched program to the corpus, counted exactly
  as a `.tcyr` is (whole identifiers in code; comments and strings blanked);
- `--per-entry` lists, for every corpus entry, the public fns it references;
- a glob that matches nothing, or a program that does not exist, is a named failure.

⚠ TEXT coverage (references), not execution coverage — that is cyrius P5-B (v6.7.x). Adjust the glob to
wherever setu's run programs live. Archive this note once adopted (or declined).
